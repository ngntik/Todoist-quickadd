# ポチっと登録

よく発生するタスクをタブ（買い物・ルーティン・不定期…自由に追加可）で切り替えながら、
ワンタップでTodoistに追加できるシンプルなWebアプリです。

## ファイル構成

```
index.html   … 画面のHTML
style.css    … デザイン
app.js       … 動作ロジック（Todoist APIとの通信、データの保存/読込）
README.md    … このファイル
```

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成する（Public / Private どちらでも可）。
2. `index.html`・`style.css`・`app.js` の3ファイルをリポジトリ直下にアップロード
   （ドラッグ&ドロップ、または `git add / commit / push`）。
3. リポジトリの **Settings → Pages** を開く。
4. 「Build and deployment」の **Source** を `Deploy from a branch` に設定。
5. **Branch** を `main`（または既定のブランチ）／ `/ (root)` に設定して **Save**。
6. 数分待つと、ページ上部に公開URL（`https://ユーザー名.github.io/リポジトリ名/`）が表示されるので、そこにアクセスする。

## 初回セットアップ（アプリ内）

1. Todoistアプリで「設定 → 連携機能（Integrations）」の一番下にあるAPIトークンをコピー。
2. アプリ右上の歯車アイコンをタップし、トークンを貼り付けて保存。

## データの保存場所について

タブ・タスク・APIトークン・既定プロジェクトは、この**ブラウザのlocalStorage**に保存されます。
そのため以下の点にご注意ください。

- 別の端末やブラウザ、シークレットモードでは共有されません。
- ブラウザの「閲覧履歴・サイトデータを削除」を行うと消えてしまいます。
- 定期的に設定画面の「エクスポート」でバックアップを取っておくことをおすすめします。

## バックアップ（エクスポート／インポート）

設定画面（歯車アイコン）から：

- **エクスポート**：タブとタスクの一覧をJSONファイルとしてダウンロードします。
- **インポート**：エクスポートしたJSONファイルを選択すると、現在の内容を上書きして復元します。

※ セキュリティのため、Todoist APIトークンはバックアップファイルに含まれません。
　別端末やブラウザ乗り換え後は、トークンだけ改めて設定画面で入力してください。
